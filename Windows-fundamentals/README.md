 Module 2: Windows Fundamentals

After building my foundation in computer hardware in Module 1, I went ahead to learn windows fundamentals and system administration. In this module, I learned about:

1) Windows installation and boot process, BIOS/UEFI, Secure Boot, Windows Recovery Environment, and system recovery.

2) File systems and permissions including NTFS, file ownership, access permissions, hidden files, encryption, and storage management.

3) User accounts and access control, local accounts, user groups, administrator privileges, and least privilege.

4) Processes, services, and startup programs. How applications run, how Windows services work, and how programs can start automatically.

6) Windows Registry and Task Scheduler. How Windows stores configuration settings and manages scheduled tasks.

7) System logs and troubleshooting. Using Event Viewer to examine system events and investigate problems.

8) Device management. Understanding drivers, hardware IDs, and common device issues.

9) Networking and command-line tools. Practicing commands such as ipconfig, netstat, tasklist and systeminfo.

I have understood some amazing terms along the way like,
A) Least privilege (giving a user or application permission for the needed task only).

B) Persistence (the ability of an attacker or malicious software to continuously execute whenever the computer restarts or signs in).

C) Encrypted data (data that is disorganized, only accessible if you have access). Among other good terms.

I have learned that understanding how an operating system works is essential to understanding how to secure it. Processes, permissions, services, network connections, and system logs all provide valuable information when investigating computer behavior.

I want to strengthen my practical skills and continue building a solid foundation for a career in cybersecurity. Moving on to module 3: Linux.
