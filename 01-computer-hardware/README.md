# Module 1 — Computer Hardware

## Objective
Understand the major components of a computer and how
they work together.

## Topics Studied
- CPU
- RAM
- Storage
- Motherboard
- BIOS/UEFI
- Power Supply
- GPU
- Cooling

## Practical Work
Disassembled an old computer to identify the major
components and understand how they are connected.

## What I Learned
- How the CPU, RAM and storage work together
- The difference between RAM and storage
- The role of the motherboard
- BIOS/UEFI fundamentals
- Basic hardware troubleshooting
